# WorkBuddy 管理框架选择器

智能选择并应用 PDCA/SMART/SWOT/5W2H 等管理框架的 WorkBuddy 技能。

## 功能特性

- **智能匹配**：根据任务特征自动推荐合适的管理框架
- **四大框架**：
  - **PDCA** - 项目执行闭环（Plan→Do→Check→Act）
  - **SMART** - 目标设定（具体/可衡量/可达成/相关性/时限性）
  - **SWOT** - 战略分析（优势/劣势/机会/威胁）
  - **5W2H** - 问题拆解（What/Why/Who/When/Where/How/How much）
- **组合使用**：支持多框架组合（如 PDCA+SWOT）
- **持续进化**：预留接口，可随时添加新的管理框架

## 安装方法

1. 下载 `management-framework-selector.zip`
2. 在 WorkBuddy 中：技能管理 → 安装技能 → 上传 zip 文件
3. 重启 WorkBuddy

## 使用方法

直接对 WorkBuddy 说：

- "用 PDCA 管理 XX 项目"
- "制定 SMART 目标：XX"
- "用 SWOT 分析 XX"
- "用 5W2H 拆解 XX 任务"

WorkBuddy 会自动加载此技能并引导您完成分析。

## 触发关键词

- "管理XX项目/任务"

## 框架选择指南

| 任务特征 | 推荐框架 |
|---------|---------|
| 项目执行、有阶段性、需要闭环 | **PDCA** |
| 目标设定、KPI制定、需要可衡量 | **SMART** |
| 战略分析、竞品分析、环境分析 | **SWOT** |
| 问题拆解、原因分析、信息收集 | **5W2H** |
| 复杂任务（多维度） | **PDCA + SWOT 组合** |
