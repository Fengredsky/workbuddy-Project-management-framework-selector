# WorkBuddy 管理框架选择器

> WorkBuddy skill for intelligent management framework selection — PDCA, SMART, SWOT, 5W2H

English | [中文](#中文)

## Description

A WorkBuddy skill that intelligently recommends management frameworks based on task characteristics. No need to memorize when to use which framework — just describe your task, and WorkBuddy will select and apply the right one.

## Supported Frameworks

| Framework | Purpose | Best For |
|----------|---------|----------|
| **PDCA** | Plan→Do→Check→Act | Project execution, periodic tasks |
| **SMART** | Specific/Measurable/Achievable/Relevant/Time-bound | Goal setting, KPI definition |
| **SWOT** | Strengths/Weaknesses/Opportunities/Threats | Strategic analysis, competitor analysis |
| **5W2H** | What/Why/Who/When/Where/How/How much | Problem analysis, task breakdown |

## Installation

1. Download from **Releases** or clone:
   ```bash
   git clone https://github.com/Fengredsky/workbuddy-Project-management-framework-selector.git
   ```
2. Open WorkBuddy → **Skill Management** → **Install Skill** → Upload the `management-framework-selector` folder
3. Restart WorkBuddy

## Usage

Just say to WorkBuddy:

- "用 PDCA 管理 XX 项目"
- "制定 SMART 目标：XX"
- "用 SWOT 分析 XX"
- "用 5W2H 拆解 XX 任务"

WorkBuddy will automatically load this skill and guide you through the process.

## 简介

根据任务特征智能选择并应用合适的管理框架（PDCA/SMART/SWOT/5W2H），让 AI 助手帮您做项目管理，而不是只提供静态知识。

## 功能特性

- **智能匹配**：根据任务特征自动推荐合适的管理框架
- **四大框架**：
  - **PDCA** — 项目执行闭环（Plan→Do→Check→Act）
  - **SMART** — 目标设定（具体/可衡量/可达成/相关性/时限性）
  - **SWOT** — 战略分析（优势/劣势/机会/威胁）
  - **5W2H** — 问题拆解（What/Why/Who/When/Where/How/How much）
- **组合使用**：支持多框架组合（如 PDCA + SWOT）
- **持续进化**：预留接口，可随时添加新框架

## 框架选择指南

| 任务特征 | 推荐框架 |
|---------|---------|
| 项目执行、有阶段性、需要闭环 | **PDCA** |
| 目标设定、KPI制定、需要可衡量 | **SMART** |
| 战略分析、竞品分析、环境分析 | **SWOT** |
| 问题拆解、原因分析、信息收集 | **5W2H** |
| 复杂任务（多维度） | **PDCA + SWOT 组合** |
